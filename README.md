# 💧 Smart Irrigation System

> Automated irrigation system that reduces farm labour and optimises water and fertilizer use without human intervention.

## 📖 Overview

An automated irrigation system built to **reduce labour on farmland** and make efficient use of water and fertilizers — all without human intervention.

## ❓ Problem

Manual irrigation wastes water, consumes a lot of labour, and often applies water and fertilizer unevenly or at the wrong time.

## ✨ Key Features

- Automatic watering based on field conditions
- Efficient use of water and fertilizer
- Reduced manual labour for farmers
- Low-cost microcontroller-based design

## ⚙️ How It Works

1. Sensors monitor field conditions such as soil moisture
2. The controller compares readings against set thresholds
3. Pumps/valves switch on automatically when the field needs water
4. Irrigation stops once the required level is reached

## 🛠️ Tech & Skills

`Arduino / Microcontrollers` `Sensors` `Circuit Design` `Embedded Software` `IoT`
